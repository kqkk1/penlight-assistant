# Penlight Supporter Helper (for MIX PENLa PRO-361)

ダウンロードありがとうございます！
本拡張機能は、MIX PENLa PRO-361のWeb設定ツールでの設定作業を補助・高速化する目的で動作します。

## 📥 導入方法
このフォルダの中にある `extension` というフォルダを、Chrome等のブラウザの「拡張機能の管理画面」に読み込ませて（パッケージ化されていない拡張機能を読み込む）ご利用ください。

## 📊 自分専用のリストを作りたい方へ
以下のURLから、テンプレート用のスプレッドシートをコピー（マイページに保存）してご利用ください。
🔗 [スプレッドシートテンプレート](https://docs.google.com/spreadsheets/d/1qQ1ezrI5ujr4YIi4hO3EmPSLRTULKtSSV_LQ1Q6SNGo/copy)
（※詳しい設定方法や使い方は、公開しているnoteの記事をご覧ください。）

## ⚠️ 仕様・注意事項
- 拡張機能は対象の設定サイト上（`penlight-supporter.onrender.com`）でのみ動作します。
- アイドル情報やカラー情報の取得のために、指定されたGoogleスプレッドシートを外部読み込みします。
- お気に入り（★）の状態や、取得したデータのキャッシュなど、一部の設定情報はブラウザの `localStorage` に安全に保存されます。
- 外部の第三者サービスへユーザーの行動データを送信するような機能は一切ありません。
- ソースコードは本GitHubリポジトリからすべて確認できます。
